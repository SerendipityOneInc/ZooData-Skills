# Consumer-feedback metric meanings

## Review populations and measures

| Metric | Meaning |
|---|---|
| Review count | The number of written reviews in the returned analysis population. |
| Product rating count | The product's accumulated number of star ratings. |
| `count` / `reviewRate` | The theme's mention count and mention proportion in the stated review population. One review may mention several themes. |
| Theme `avgRating` | The mean star rating of reviews associated with that theme. |
| Opinion expressed in reviews | Positive, negative or neutral opinion expressed in review text, interpreted under the returned classification. |
| Source and coverage | The data route, product/variant selection, observed dates and readable text represented in the sample. |
| Stored review search population | Reviews returned for an ASIN represent its parent-review population. The review text or returned variant metadata establishes whether an experience concerns a particular variant. |

## Consumer dimensions

| Metric | Meaning |
|---|---|
| `painPoints` / `issues` | Expressed unmet concerns and reported product/use problems. |
| `positives` / `improvements` | Stated favorable experiences and consumer-requested changes. |
| `buyingFactors` | The reasons or criteria consumers state for choosing the product. |
| `keywords` | Terms identified in consumer text. |
| `userProfiles` / `scenarios` | Consumer characteristics and described use situations. |
| `usageTimes` / `usageLocations` / `behaviors` | Described times, places and actions associated with use. |
