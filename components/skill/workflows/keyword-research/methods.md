# Choose evidence for the question

1. **Expand a seed.** Use [related queries](../../datas/keyword-expansion/definition.md). Keep one row per term, site and week. Group by the category, attribute, use or setting expressed in the query. Separate adjacent categories. Preserve the retrieval order within groups. Finish with the returned baseline measures for an expansion-only request.
2. **Study or compare named terms.** Use [keyword profiles](../../datas/keyword-profile/definition.md) on the same observation week. Select the demand, competition, search structure or annual seasonality dimensions relevant to the question. Use [keyword statistics](../../datas/keyword-statistics/definition.md) for a baseline-only question or a specified raw measure missing from the available evidence.
3. **Study changes.** Use the [demand trend profile](../../datas/keyword-trend-profile/definition.md) for direction and volatility over the requested windows. Retrieve [weekly query records](../../datas/query-weeks/definition.md) when the user asks for individual weeks, a weekly chart, or when a specific timing question remains. Annual seasonality comes from the keyword profile.
4. **Study an ASIN's terms.** Use [traffic terms](../../datas/traffic-terms/definition.md) to identify observed terms for the target product. For a question about change on named terms, use [weekly ASIN and query visibility](../../datas/traffic-term-weeks/definition.md). Align exposure and placement by type with the query's demand or ABA rank for the same weeks. Use weekly query records only if this context is missing. Add keyword profiles for the selected terms when the question asks for their market conditions.
5. **Prioritize candidates when requested.** Compare relevant, same-period candidates on the seller's criterion. Use profiles for competition, trends for growth and the target ASIN’s observed term performance, operating stage and goal for product-specific priorities. State the coverage of the comparison.
