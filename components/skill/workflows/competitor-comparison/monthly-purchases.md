# Monthly purchases over the last three complete months

1. Confirm Amazon US and the selected ASINs, including the seller’s ASIN when requested. For specific calendar months, use the monthly sales data method linked in step 3 directly with the requested start and end months and align those months. For “the last three complete months”, pass the ASINs as separate arguments to the [request planner](plan_monthly_purchases.py) and follow its status below. It selects finalized months as of today (UTC).
2. For `confirm_asins`, ask for one to three distinct valid ASINs. Show all supplied candidates and wait for the selection. For `outside_coverage`, report the unavailable period. Neither status starts a read.
3. For `ready`, match each planned ASIN and its months against existing data. If the budget cannot cover all missing ASINs, ask which ones to include before querying. For each remaining ASIN, use **zoodata-product-sales-trend** once with the planner's arguments. The [bundled data instructions](../../datas/product-sales-trend/definition.md) support the same operation in a standalone workflow.
4. Align each selected ASIN and its parent purchase lower bounds by calendar month, retaining the parent identifier returned for each month. Include all three months even if some are unavailable. If one read fails, keep the other results and mark the unavailable cells. Report which purchase tiers rose, fell or stayed the same where both observations exist.
