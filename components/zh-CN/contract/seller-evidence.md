# 商家报表与成本口径

<a id="identify-report-scope"></a>

## 识别报表范围

1. 分析用户提供的 SQP、广告和成本资料，不假定能够直接访问商家账户。
2. 保留报表的站点、品牌或 ASIN 视图、期间、每行对应的维度和归因窗口。截图缺少分析必需的信息时，指出具体缺少的上下文，不自行推断。

<a id="interpret-sqp-data"></a>

## 解读 SQP 数据

1. Search Query Volume 表示查询次数；展示、点击、加购和购买分别统计各阶段的事件数。
2. 品牌或 ASIN 的阶段份额 = 该主体在该阶段的事件数 ÷ 所选视图下该阶段的总事件数，不能用查询次数作分母。
3. 比较阶段份额时，保留各阶段的主体数量和总数量；数量未提供时保持缺失，不用其他阶段的数量反推。
4. SQP 本身不提供广告花费、出价或成本，不能用其漏斗数量计算 CPC、ACOS、ROAS 或利润。

<a id="interpret-advertising-data"></a>

## 解读广告数据

1. 区分买家实际搜索词与广告主设置的关键词或商品投放目标。保留广告活动、广告组、位置和匹配方式，按报表粒度汇总，不将汇总行与其明细重复相加。
2. 归因销售额是收入，不是利润；CPC 是每次点击的花费，不是当前出价。

| 指标 | 公式 |
|---|---|
| CPC | 花费 ÷ 点击数 |
| CVR | 归因订单数 ÷ 点击数 |
| ACOS | 花费 ÷ 归因销售额 |
| ROAS | 归因销售额 ÷ 花费 |

<a id="interpret-costs-and-targets"></a>

## 解读成本与目标值

1. 区分报价、估算成本和已发生的成本，并说明金额是每件成本还是期间总额。
2. 单位贡献 = 净成交价－到岸成本－平台及履约费－获客成本－预计退货或折让。列明纳入的成本项，同一项目不重复扣减；关键成本缺失时，标为已知成本下的测算，不称为完整利润。
3. 贡献率 = 单位贡献 ÷ 净成交价，仅在净成交价为正数时计算。
4. 预算及目标 ACOS、ROAS 是约束条件，不作为实际花费、收入或利润的计算输入。
