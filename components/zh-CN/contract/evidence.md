# 数据口径与结论依据

<a id="preserve-measurement-scope"></a>

## 保留统计口径

1. 提取或分组数据时，保留任务要求的对象标识和基础指标，以及来源、站点、期间、单位、分母、样本范围和筛选条件。
2. 数值一致性核验前，核对对象范围与粒度、总体与样本选择、业务日期与统计窗口、指标定义、单位及分母；Top N 还需核对排序指标和截取数量。口径不同或尚未确认一致时，分别报告观测结果，不将数值差异当作数据冲突。
3. 部分记录求和或本地排序，只代表该样本的小计或排名，不能称为总体总量或全局排名。服务端 Top N 保留实际查询条件和排序依据。
4. 空结果表示查询条件下没有匹配记录，不外推为市场需求为零、没有竞争或没有变化。

<a id="handle-missing-values-and-derived-calculations"></a>

## 处理缺失值与派生计算

1. 原值照实保留，区分 0、false、null、字段缺失和未返回期间。未知只用于未取得的信息；标注前检查原始响应，不能把本地未读取或未展示当作数据缺失，也不能将缺失补成零值。
2. 计算和排名只使用已取得的数值，并保留缺失标识。没有有效输入，或分母为零、不可用时，标为不可计算；排序指标缺失的对象不参与数值排名。
3. 汇总比率时，先合计对应分子和分母，再相除，不直接平均各行比率。每项派生计算保留输入和公式。
4. 绝对差值、相对变化率和百分点变化分别计算、标注，不能混用。
5. 时间序列保留缺口，不插值；未完成周期按实际覆盖范围标注，不视为完整周期。

<a id="establish-supported-data-findings"></a>

## 形成有依据的数据发现

1. 按接口定义，以 ZooData 成功返回的数据作为事实依据。任何时候都不要求卖家确认、核实或提供证明来支持 ZooData 返回的数据。
2. 观测看似矛盾时，核对对象、期间、单位和统计范围。口径不同时分别解释；仍有矛盾时保留原值，说明具体不一致，并在查询限制内按当前任务的方法补充佐证，不能因关系尚未解释就将返回值标为未知。
3. 每项数据发现对应返回值或明确计算，不补写未提供的商品属性、买家行为或评分公式。
4. 返回的分类按其统计窗口、范围和支撑观测解释，不改写成确定的未来结果。
5. 原因判断须有支持该关系的测量或对照结果；只有同步变化或时间先后时，只报告关联，不写确定原因。
