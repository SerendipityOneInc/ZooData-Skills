# 组织关键词研究报告

在报告开头说明站点、核心词或指定词，以及实际统计周或期间。根据下表设置报告的 `task`。同时要求拓词与推荐时使用 `expansion`，把推荐词放在末尾。

| 任务 | 展示顺序 |
|---|---|
| `expansion` 拓词 | 说明候选范围和分类依据。每组使用窄表，每行一个词，分别列出相关度、周预估搜索量和 ABA 搜索频率排名。用户要求推荐时，以选中的词和各自的决定性证据收尾。 |
| `profile` 画像 | 先列研究词及其搜索需求，再并排比较用户关心的同期指标。每项指标写明名称和单位，差异旁说明其业务含义。只问基础数据时，仅呈现所需指标。 |
| `trend` 趋势 | 展示指定期间的需求方向，以及已取得的期初值、期末值和变化幅度。ABA 排名单独标注。逐周展示时保留缺失周；量级不同的指标分轴或分图。 |
| `asin-terms` 商品关联词 | 标出 ASIN，在实际流量词旁列出该商品的曝光、位置和词本身的搜索需求。自然位与广告位分开。展示变化时，同期对照曝光、位置与词的搜索量或 ABA 排名。 |

使用译词查询时，在报告范围中并列标明用户输入的核心词和实际查询词。返回的关键词保留原文，标题、等级和判断使用对话语言。
