# 评估指定候选

## 确认用户要求评估的候选商品

1. 仅用卖家给定数据时，按其提供的名称或编号标识候选。需要查商品库或区分同名商品时才索取 ASIN。默认评估一个候选，只有用户明确选定时才比较，最多三个。对象不明确或超过三个时，取数前请用户选定。查库前执行[候选范围检查](../../../../skill/workflows/product-selection/assessment_scope.py)，传入选定的 ASIN；仅在明确比较时加 `--compare`。返回 `ready` 才按其清单评估。筛选清单仍按原范围展示。
2. 综合评估以商品如何成长为主线，按下表取证。用户只问销量是否持续增长等具体问题时，在同一评估中只看相关指标。复用已有数据，遵守用户给定的费用上限。
3. 沿用用户指定期间。综合评估未指定期间时，以最近六个完整月为共同观察期：销量按月，商品历史取同一期间，曝光取该期间的完整周。新品从首次可观察日期起算。某项数据覆盖较短时标出实际期间，只对照重合的时段。

## 判断商品是怎样成长的

| 维度 | 看哪些证据，回答什么问题 |
|---|---|
| 销量 | 用[月度购买量](../../datas/product-sales-trend/definition.md)比较所选 ASIN 的月购买量下限。看起点、何时升档或回落，以及此后有几个月维持在新水平。对照父体同期购买量，说明本商品和整个变体家族的走势是否一致。 |
| 价格 | 用[商品历史](../../datas/product-history/definition.md)查看各期售价，用[商品详情](../../datas/product-detail/definition.md)确认件数和当前规格。区分长期售价、短期降价和价格回升。跨商品比较时统一套装规格，或换算单件价格。 |
| 自然曝光 | 用[曝光趋势](../../datas/traffic-trend/definition.md)看自然搜索曝光在增加、持平还是回落，用[流量来源](../../datas/traffic-structure/definition.md)看对比时点的预估曝光点数及其占比。若占比上升但点数减少，应说明自然曝光也在减少。 |
| 广告曝光 | 复用同一组数据，查看广告位预估曝光的走势和占总曝光的份额。优先用返回的广告合计；分渠道合计时，只加同口径且互不重叠的广告位。评估的是商品在广告位被看见的程度。 |
| 畅销排名（BSR） | 复用商品历史，在同一排名类目内看名次何时前移、能否保持，数值越小名次越靠前。大类和子类分开看，换类目前后分段判断。对照排名与购买量变化是否发生在同一阶段。 |
| 评分 | 在同一份商品历史中看累计评分数在各期间增加或减少了多少，并对照星级变化。评分数反映评价积累；保留实际下降和数据缺口，换父体时分开比较。 |
| 买家评价 | 通过[评价画像](../../datas/product-review-profile/definition.md)查看候选商品经常受到的好评和抱怨。同一期间每个已确认的父体只取一份画像，同父变体共用这份反馈。判断某个问题是否越来越常见时，再用[带日期的评论样本](../../datas/review-search/definition.md)比较两个不重叠、覆盖方式相同的时段，分别列出样本量和提及比例。只有汇总画像时，只说明已观察到的主题。 |

1. 每个商品 ASIN 用一次商品历史查询同时取得每日价格、大类排名及所属类目（`bsr`、`bsrCategory`）、小类排名及所属类目（`subBsr`、`subBsrCategory`）。需要评价趋势时一并取得星级和评分数。多个候选可批量查询曝光画像。趋势画像覆盖四周。判断整个成长期间、定位转折或绘制走势时，画像覆盖不足的部分使用[逐周曝光记录](../../datas/traffic-weeks/definition.md)，复用其中的自然和广告数据；已有记录充分时跳过重复画像。
2. 按变化经过组织判断：商品起点如何、何时出现变化、之后哪些表现维持或回落。将购买量与同期价格、曝光、排名及评分积累对照，指出哪些信号一致、哪些不同步。只有一个观测值时描述现状；未取得的指标保留未知。
3. 比较候选时统一站点、单位及商品层级，选择可比的经营阶段和期间。结合用户的明确条件判断适配程度。降价或曝光增加与销量变化同期发生，只能说明时间重合。判断广告效率需要卖家的广告报表。

## 按选品问题补充证据

1. 需要可比商品时使用[竞品查找](../../datas/product-competitors/definition.md)，核对用途和规格。用户询问某商品关键词对应的价格带或品牌分布时，可按已筛出的商品汇总，注明统计范围、分母和覆盖量。按购买量下限计算份额时，只使用同口径数值，并标明计算依据。
2. 类目环境会影响候选判断时，从[类目市场研究](market-research.md)选取对应证据。类目整体与候选样本分别统计。
3. 用户想知道候选通过哪些词获得曝光时，使用[商品曝光词](../../datas/traffic-terms/definition.md)。
4. 比较经营门槛时，使用卖家提供的成本、费用或经营限制，列出实值、门槛和差额。缺少必要输入时，说明哪一项比较尚无法完成。
