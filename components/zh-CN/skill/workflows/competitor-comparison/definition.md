# 竞品洞察研究

可分析自家商品、竞品或指定的一组商品。根据卖家的问题选择一项任务，沿用已给出的站点、商品、日期和预算。

| 卖家想了解什么 | 分析任务与结果 |
|---|---|
| 这款商品的产品定位和市场表现如何？ | 围绕给定的一个 ASIN，分析产品卖点与定价、近期销量走势、流量来源和买家反馈。 |
| 这些美国站商品最近三个完整月的购买量有什么变化？ | 按相同的三个月份展示每款商品的月购买量下限。 |
| 指定商品近期改了什么？ | 按 ASIN 和期间核查标题、主图及价格，交付有日期的变更记录。 |
| 哪些商品适合作为我的竞品？ | 根据目标 ASIN 或商品资料，在已确认范围内找出可比 ASIN，说明纳入理由。 |
| 这些竞品整体表现如何？ | 对比规格、经营表现、流量来源和历史变化。卖家明确要求深度对比时加入买家反馈。 |
| 这些商品在某一指标上有何差异？ | 在指定期间比较用户所问指标，例如月营收或价格走势。 |
| 我的商品可以在哪些方面与竞品形成差异？ | 比较目标商品和竞品在相关产品特征、页面信息及买家体验上的差异。 |

1. 分析用户提供的记录时，沿用其商品标识、单位和日期。若只比较两款已明确商品的指定指标，可直接使用用户给出的名称或代号。需要查询美国站新数据时，使用选定的 ASIN 和 ZooData 连接器。若某项数据无法查询，说明用户可提供哪些记录来完成这项比较。
2. 用户只问美国站商品最近三个完整月的购买量时，读取并执行[《比较最近三个完整月的购买量》](monthly-purchases.md)。若只查指定 ASIN 在一段时间内的标题、主图或价格变化，直接使用[商品历史](../../datas/product-history/definition.md)。其他问题按[对比方法](methods.md)为缺少的指标选择数据 Skill，按随包说明取数并复用结果。
3. 按[证据规则](../../../contract/evidence.md)处理数据，新增查询前按[MCP 调用规则](../../../contract/query.md)取数。
4. 按[任务提纲](report-outline.md)组织发现，遵循[展示规范](../../../contract/report.md)。独立使用时，按 [HTML 报告指南](../../../tools/report/definition.md)生成一份报告。在专家会话中，将同一份发现和提纲交给专家解读，最终生成一次报告。用户明确指定其他格式时按其要求交付。
