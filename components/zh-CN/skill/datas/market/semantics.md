# 市场指标含义

<a id="market-and-sample-populations"></a>

## 市场与样本范围

| 指标 | 含义 |
|---|---|
| 父体商品口径 | 市场商品以父体商品（SPU）为单位，合并同一商品的变体。 |
| 商品包含范围 | 每个类目市场是否包含其后代类目的商品。 |
| 样本选择 | 按指定月销量或收入规则选取的最多 100 个头部 SPU。 |
| `totalProductCount`、`totalMonthlySales`、`totalMonthlyRevenue` | 选定范围的全类目 SPU 数及对应近三十天销量和收入；商品目录记录总数属于另一统计总体。 |
| `sampleProductCount`、`sampleMonthlySales`、`sampleMonthlyRevenue` | 所选样本的商品数量、销量和收入。 |
| 样本均值 | 对应指标有效观测中的商品均值，各指标有效样本数可能不同。 |
| `resolvedDate` | 返回快照的实际业务日期。 |
| 金额与比例 | 市场金额以美元返回，比例以小数返回；浮点指标采用接口规定的舍入方式。 |

<a id="distributions-and-concentration"></a>

## 分布与集中度

| 指标 | 含义 |
|---|---|
| 分组商品占比 | 按返回归组规则划入该组的样本商品比例。 |
| 销量或收入份额 | 该分组或对象的销量、收入占对应样本总量的比例。 |
| 内容和卖家国家分组 | 一个商品满足多个返回分组定义时，可以同时属于多组。 |
| Top N 集中度 | 按样本销量或收入排序依据，前 N 个对象合计占据的份额。 |
| 卖家国家 | 样本中卖家记录的所在国家。 |
| 星级和评分数 | 分别表示星级分值和累积评分数量。 |

<a id="numeric-distribution-boundaries"></a>

## 数值分桶边界

价格和上架年龄区间采用**前闭后开**：`lowerBound <= value < upperBound`。星级评分采用**前开后闭**，包含最高有效星级 5。评分数按连续整数分段，采用**前闭后闭**：`lowerBound <= value <= upperBound`。明确无上界的尾段为 `value >= lowerBound`。等值桶只包含指定值，null 边界不是 0。下表定义统一区间口径，当前接口明确给出的边界规则描述该次返回数据的实际归组。

| 维度 | lowerBound | upperBound | 区间 |
|---|---:|---:|---|
| 星级 | 0 | 2 | (0, 2] |
| 星级 | 2 | 3 | (2, 3] |
| 星级 | 3 | 3.5 | (3, 3.5] |
| 星级 | 3.5 | 4 | (3.5, 4] |
| 星级 | 4 | 4.3 | (4, 4.3] |
| 星级 | 4.3 | 4.5 | (4.3, 4.5] |
| 星级 | 4.5 | 5 | (4.5, 5] |
| 评分数 | 1 | 50 | [1, 50] |
| 评分数 | 51 | 100 | [51, 100] |
| 评分数 | 101 | 200 | [101, 200] |
| 评分数 | 201 | 300 | [201, 300] |
| 评分数 | 301 | 500 | [301, 500] |
| 评分数 | 501 | null | [501, +∞) |
| 上架年龄（日历月） | 0 | 1 | [0, 1) |
| 上架年龄（日历月） | 1 | 3 | [1, 3) |
| 上架年龄（日历月） | 3 | 6 | [3, 6) |
| 上架年龄（日历月） | 6 | 12 | [6, 12) |
| 上架年龄（日历月） | 12 | null | [12, +∞) |

| 边界情形 | 含义 |
|---|---|
| 有效星级 | 大于 0 且不高于 5；0、null 和超出有效范围的值属于来源的其他或未知组。星级末档 (4.5, 5] 包含有效最大值 5，高于 5 的值仍无效。 |
| 整数评分数 | [1, 50] 包含 1 至 50，下段从 51 开始；返回的 eq_0 桶单独表示评分数恰好为 0。 |
| 价格边界 | 实际返回的价格区间前闭后开，末档无上界；同一价格桶编码在不同市场或日期不一定对应相同区间。 |
| 日历月年龄 | 设 D_n = DATE_SUB(resolvedDate, INTERVAL n MONTH)，首次上架日为 L，则年龄 [a, b) 对应 D_b < L <= D_a；末档对应 L <= D_12。边界按日历月计算，不按固定 30 天倍数计算。 |
| 当天及未知上架日 | 当天上架的年龄为 0，属于 [0, 1)；上架日期缺失不能证明年龄至少 12 个月，未来日期不能证明有效的非负年龄。 |

<a id="history-and-launch-composition"></a>

## 历史与新品构成

| 指标 | 含义 |
|---|---|
| 历史观测点 | 已发布月末快照及该期全市场和所选样本指标。 |
| 历史样本 | 每个月末独立选取的头部样本，其商品成员可以变化。 |
| 新品窗口 | 在指定首次上架时长窗口内的商品，统计范围沿用返回的全市场或样本口径。 |
| 上架构成观测点 | 当前样本中首次上架于指定月或年的商品数量；其中日期表示首次上架期间，不是样本快照日，该响应不提供单独的快照日期字段。 |
