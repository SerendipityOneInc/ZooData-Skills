# 消费者反馈指标含义

<a id="review-populations-and-measures"></a>

## 评论范围与指标

| 指标 | 含义 |
|---|---|
| 文字评论数 | 返回分析范围中的文字评论数量。 |
| 商品评分数 | 商品累积星级评分数量。 |
| `count` 与 `reviewRate` | 该主题在指定评论集合中的提及数量和比例，一条评论可以提及多个主题。 |
| 主题 `avgRating` | 与该主题相关评论的平均星级。 |
| 评价倾向 | 评论文本表达的肯定、否定或中性态度，按接口返回分类解释。 |
| 来源与覆盖范围 | 样本代表的数据来源、商品和变体选择、观测日期及有效正文范围。 |
| 已存评论查询范围 | 指定ASIN返回的是所属父体的评论人群。是否属于某个变体，由评论原文或返回的变体信息说明。 |

<a id="consumer-dimensions"></a>

## 消费者分析维度

| 指标 | 含义 |
|---|---|
| `painPoints` 与 `issues` | 表达出的未满足关注点及商品或使用问题。 |
| `positives` 与 `improvements` | 消费者表达的正面体验和改进要求。 |
| `buyingFactors` | 消费者陈述的购买原因或选择标准。 |
| `keywords` | 从消费者文本中识别出的用词。 |
| `userProfiles` 与 `scenarios` | 消费者特征及所描述的使用情境。 |
| `usageTimes`、`usageLocations` 与 `behaviors` | 描述出的使用时间、地点和行为。 |
