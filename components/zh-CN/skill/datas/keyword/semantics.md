# 关键词指标含义

<a id="search-demand-volume-and-relevance"></a>

## 搜索需求量与相关度

| 指标 | 含义 |
|---|---|
| 预估搜索次数 | 完整搜索词在接口统计窗口内的预估搜索次数。 |
| ABA 搜索频率排名 | 指定站点和期间内，该词相对其他搜索词的搜索频率位置，数字越小越靠前。排名变化反映相对搜索频率变化，不代表搜索次数的绝对变化。 |
| 拓词相关度 | 接口返回的种子词与候选词的相关程度，用于排列相关关键词。 |

<a id="keyword-profiles"></a>

## 关键词画像

| 分析维度 | 指标 | 含义 |
|---|---|---|
| 搜索需求量 | 需求规模 | 搜索词对应的搜索需求量，结合预估搜索次数和 ABA 排名说明。 |
| 竞争画像 | 前 20 自然位竞争难度 | 竞争前 20 个自然位置的相对难度，使用返回的分级和解释。 |
| 竞争画像 | 供给饱和度 | 接口返回的商品供给综合评估，参考搜索结果商品数、标题含词比例，以及已提供的统计商品数。标题含词比例是参考指标之一，不是综合等级，也不是公开的分级公式。 |
| 竞争画像 | 搜索结果商品数（`searchResultSkuCount`） | 统计期间内，来源记录的搜索结果商品总数最大值。 |
| 竞争画像 | 统计到的商品数（`observedSkuCount`） | 本期实际统计到的去重商品数量，与来源记录的搜索结果商品总数不是同一统计范围。 |
| 竞争画像 | 标题包含该词的商品比例（`titleKeywordDensity`） | 每个有效日按“标题含词的去重商品数 ÷ 当日合格商品数”计算比例，再对有效日取平均。衡量商品标题中的关键词覆盖情况。 |
| 竞争画像 | 自然搜索前列商品的评分与销量 | 前 48 个自然搜索商品的平均星级、按返回字段定义区分的评分数或文字评论数，以及平均销量（`top48OrganicAverageRecentSaleCount`）。销量统计期间沿用来源字段的实际定义，数据观察周不代表销量回溯期间。这些指标描述当前排在前面的商品水平，不是新品必须达到的最低要求。 |
| 搜索结构画像 | Top3 集中度 | ABA Top3 商品的点击及转化份额，分别按对应事件类型解释。这些份额描述集中程度，不是转化率。 |
| 搜索结构画像 | 品牌结构 | 观测竞争在品牌之间的集中程度，使用返回的品牌集中度和品牌份额。 |
| 搜索结构画像 | 广告覆盖率 | 观测商品中出现于广告位的去重商品比例。 |
| 需求季节性 | 年度季节性 | 历史需求的年度周期特征；有历史高峰记录时，用其说明高峰发生期间。 |

<a id="trend-profiles-and-weekly-statistics"></a>

## 趋势画像与周度统计

| 指标 | 含义 |
|---|---|
| 需求趋势 | 所选窗口内接口返回的需求变化方向。 |
| ABA 排名趋势 | 所选窗口内搜索频率排名的改善、平稳或变差。 |
| 波动程度 | 该窗口内需求的起伏程度。 |
| 最新观测在窗口内的位置 | 最新一期处于该窗口数值范围的高位、中间或低位。 |
| 周度观测值 | 某个返回周的搜索量、ABA 排名或 Top3 份额，保留该周的起止日期。 |
| 首尾变化率 | 窗口首值与末值之间的相对变化，只描述这两个观测值；接口返回的趋势分类还使用窗口内的观测数据。 |
